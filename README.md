# Pocket Gullak — Voice-Based Expense Tracker

A simple, browser-based personal finance application that helps users record daily expenses, understand spending habits, and track savings through a clean, responsive interface.

## Live Demo

**[Launch Pocket Gullak](https://anushka-2607.github.io/Pocket-Gullak/)**

## Features

- **Voice-Based Expense Entry:** Record expenses by speaking instead of entering each expense manually.
- **Multiple Expense Recognition:** Enter multiple expenses in one spoken description.
- **Manual Expense Entry:** Add expense details using the interface.
- **Expense Dashboard:** View expense summaries and spending insights.
- **Savings Tracking:** Monitor savings goals and progress.
- **Local Data Storage:** Retain expense records in the browser using LocalStorage.
- **Responsive Interface:** Use the application on desktop and mobile screens.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Web Speech API, where supported by the browser
- GitHub Pages

## How to Use

1. Open the [live application](https://anushka-2607.github.io/Pocket-Gullak/).
2. Add an expense manually or use voice entry if your browser supports it.
3. Enter multiple expenses in a spoken description to try batch expense entry.
4. Review your spending dashboard and savings information.

## Privacy and Data Storage

Pocket Gullak stores expense records in browser LocalStorage. The current static application does not require a backend database for this storage approach.

- Expense records are stored separately in the browser used to access the application.
- Records do not automatically synchronize between devices or browsers.
- Clearing browser data may remove locally stored expense records.
- Avoid entering sensitive financial information into a public demonstration.
